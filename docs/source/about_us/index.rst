========
About Us
========

clustvartools is an open source `Python <https://www.python.org/>`_ library for clustering of variables. 
It will always be :math:`100\%` open source software and free for all to use.
It is released under the liberal terms of the `MIT Licence <https://github.com/enfantbenidedieu/clustvartools/blob/main/LICENSE>`_. 

It is developed in the open on `GitHub <https://github.com/enfantbenidedieu/clustvartools>`_.
